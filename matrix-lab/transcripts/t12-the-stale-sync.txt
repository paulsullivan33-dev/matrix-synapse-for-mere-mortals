# A trap the lab met while capturing the invite in t06: a
# one-shot /sync answer can LAG reality — and the two flavours
# of sync can disagree with each other moments apart. During
# the t06 capture the bare sync was the stale one; below, the
# full_state sync is. Ground truth first, from the dedicated
# endpoints, which never disagreed with each other:

$ curl -s http://127.0.0.1:8008/_matrix/client/v3/joined_rooms -H 'Authorization: Bearer <bob>'
{
  "joined_rooms": [
    "!MvRSxCPghox--9v33vm6GHee9eraBdJaVfa4mUBI-fg",
    "!FxxV4_i7hlcTN_ef-eA7ruzlt63FL8FoJoXfGVMczIQ"
  ]
}

$ curl -s 'http://127.0.0.1:8008/_matrix/client/v3/sync?timeout=0' -H 'Authorization: Bearer <bob>'   (excerpt)
{
  "invited_rooms": [],
  "joined_rooms": [
    "!FxxV4_i7hlcTN_ef-eA7ruzlt63FL8FoJoXfGVMczIQ",
    "!MvRSxCPghox--9v33vm6GHee9eraBdJaVfa4mUBI-fg"
  ]
}

$ curl -s 'http://127.0.0.1:8008/_matrix/client/v3/sync?timeout=0&full_state=true' -H 'Authorization: Bearer <bob>'   (excerpt)
{
  "invited_rooms": [
    "!FxxV4_i7hlcTN_ef-eA7ruzlt63FL8FoJoXfGVMczIQ"
  ],
  "joined_rooms": [
    "!MvRSxCPghox--9v33vm6GHee9eraBdJaVfa4mUBI-fg"
  ]
}

# Verdict at capture time: bob had joined BOTH rooms (the
# joined_rooms endpoint above, and the member state agreed).
# The bare sync agreed this time; the full_state sync still
# showed The Garden Shed as an unanswered invite. During the
# earlier t06 capture the bare sync was the stale one instead.
# Lesson written into the troubleshooting chapter: treat one
# sync answer as a snapshot that may lag, and when it matters,
# check the room endpoints — they were consistent every time.
